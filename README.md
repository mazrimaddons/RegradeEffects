# Mazrim Regrade Effects

- Pick a regrade scene and speed from **Regrade Effects** beside the game's Regrade window.
- New profiles use **Random scene** at **Cinematic** speed. Random rolls one of the six regular cinematics for each attempt.
- Click **Test** beside any scene to choose an outcome or play a random preview at that speed.
- Customize the **Basic CS Skins** reel by turning individual weapon skins on or off. It features the M4A4 Howl for Divine and Epic and the AWP Dragon Lore for Legendary and Mythic.
- Use the **Odds Planner** to preview each scene and estimate your odds over multiple attempts.
- Ship-component regrades automatically play **Forge Voyage**.

Open **Addons → Mazrim Regrade Effects → Settings** for the Odds Planner and Case opening switch. The addon runs independently of Mazrim Tools. The optional AAC Sound Service plays extra sound cues.

If the standalone addon imports a disabled setting from Mazrim Tools, click **Regrade effects OFF** in its Settings to turn it on.

For a manual install, extract the release ZIP into `Documents/AAClassic/Addon/` and add `mazrim_regrade_effects` to `addons.txt`. Existing 0.4.x users should merge this release into their existing addon folder, then start the addon on each character to migrate their profiles. Classic Addon Manager carries the `.data` folder forward on later updates.

Basic CS Skins weapon artwork comes from [Valve's Counter-Strike item listings](https://steamcommunity.com/market/search?appid=730). Aguru's original sprite uses the [ArcheAge Daru guide](https://archeage.ru/game/perevoploshchenie-daru/) as a visual reference.
